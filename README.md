# Product Card React App

A responsive product listing application built with React using reusable components and CSS Grid layout.

## Features

* Reusable `Card` component
* Dynamic product rendering using `.map()`
* Props-based data flow
* Responsive product grid layout
* Clean UI with hover effects

## Tech Stack

* React
* JavaScript (ES6+)
* CSS3
* Vite

## Key Concepts Practiced

* Component-based architecture
* Props and prop destructuring
* Rendering lists with `.map()`
* Spread operator (`...product`)
* Responsive layout design

## Run Locally

```bash
npm install
npm run dev
```
